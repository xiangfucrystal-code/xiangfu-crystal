# Design — Xiangfu Crystal (The Illuminated Catalogue)

Site-specific design system generated by the canvas-designer SubAgent on 2026-09-08; user-approved on 2026-09-08 (template choice: A — Alpine-Lumina-Serif ivory exhibition style; direction "批准，按此推进").

## Product goal & audience
B2B wholesale catalog + inquiry machine for Xiangfu Crystal (Donghai Xiangfu Jewelry Trading Co., Ltd.). Converts EU/US importers, wholesalers, gift/retail buyers into RFQ leads. SEO-first: strong category pages + editorial Journal targeting long-tail keywords ("wholesale crystal figurines", "crystal gift supplier", "crystal balls wholesale"). No cart/checkout/prices anywhere (prices shown as "On request").

## Visual direction
"Ivory editorial luxury with an ink-lit hero": warm ivory surfaces (#f6f1e7), champagne-gold detail accent (max 2 visible per screen), deep warm noir stages for spotlight/footer. Large light-weight serif display (Cormorant Garamond), reading serif body (EB Garamond), IBM Plex Mono metadata. Hairline 1px rules, flat 0-radius, generous whitespace, exhibition-catalog plate grammar (plate IDs XF-####, mono captions). Mood: exhibition-catalog calm, ivory gallery light, champagne sparkle sparingly, no purple/gradients/gloss.

## Vendor Grounding
- Baseline: Alpine-Lumina-Serif (La Luce Alpina). Applies to this new site (gate not skipped).
- Anti-ai-slop: no indigo, no two-stop gradients, no emoji icons, display serif honored, no rounded cards, no invented metrics/testimonials (stat/quote bands render nothing until client-supplied), no runtime placeholder CDN images (all local assets).
- Token source: Alpine tokens.css translated + adapted (see tokens.css in project).
- Component fixture: components.html (buttons, fields, cards, nav).
- Intentional deviations (user-confirmed): warm ivory/cream surfaces replace the system's pastel zonal tints; champagne-gold detail accent; noir spotlight/footer stages (baseline has none); web font substitution (self-hosted Cormorant Garamond / EB Garamond / IBM Plex Mono — external font CDNs banned by frontend policy); fixed index sidebar re-expressed as responsive index list / anchor rail.

## 2026-09-08 Homepage Hero Redesign

- User feedback: the previous first screen had an oversized English headline inside a narrow copy column, causing word-by-word wrapping; the original storefront images were enlarged beyond their useful resolution and looked blurred.
- Typography correction: desktop hero copy now uses a stable 560px maximum panel with controlled heading measure, Chinese two-line target, English two-to-three-line target, 0.98–1.14 heading leading, consistent left alignment, and a restrained company fact strip. Mobile uses a full-width lower content panel with a 2.1–2.85rem title range.
